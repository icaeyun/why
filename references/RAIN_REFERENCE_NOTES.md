# Rain Quality Reference Notes

## references/rain-demo
Purpose:
- Real 3D falling rain particle structure.
- Camera/exterior-area based reusable rain particles.

Use for:
- nearRainStreaks
- particle recycling
- performance-safe falling rain

Do not use for:
- CSS overlay rain
- raindrops-on-glass effect only

## references/faraz-rain-puddle
Purpose:
- Wet road, puddle shader, splashes, ripples.

Use for:
- outdoor wet ground material
- ground splash particles
- ripple visual direction

Warning:
- GPL-3.0 reference. Do not copy/paste directly into this project.

## references/faraz-storm-at-midnight
Purpose:
- Overall rainy-night realism reference.
- Rain mood, thunder, sound layering, ripple shader reference.

Use for:
- cinematic rainy diner atmosphere
- storm/night mood
- rain sound/thunder balance

## references/daniel-ilett-rain-urp
Purpose:
- Unity VFX Graph + Shader Graph rain system reference.

Use for:
- falling raindrops + puddle map + splash structure
- conceptual design, not direct Three.js code copy

## references/react-weather-effects
Purpose:
- Weather mode UI, rain/storm/fog layering, shader organization.

Use for:
- weather mode toggle structure
- fog/storm/lightning reference
- UI organization ideas
